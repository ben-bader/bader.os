# Creative Direction

## Vision

This portfolio is not a personal website.

It is an interactive digital experience.

It should communicate engineering excellence, creativity, precision and craftsmanship before visitors even begin reading.

The experience should feel timeless rather than trendy.

Every interaction should communicate quality.

Every pixel should have a purpose.

Every animation should reinforce storytelling.

The portfolio should be remembered long after the visitor leaves.

# White Space

Whitespace is not empty.

Whitespace creates rhythm.

Whitespace creates elegance.

Whitespace creates hierarchy.

Prefer too much whitespace over too little.

Never overcrowd sections.

---

# Motion Philosophy

Motion should explain.

Motion should guide.

Motion should reward.

Motion should never distract.

Motion should feel physical.

Objects have weight.

Objects have inertia.

Objects have anticipation.

Objects have follow-through.

Objects should never instantly appear.

Everything enters naturally.

Everything exits naturally.

---

# Scroll Philosophy

Scrolling should feel like walking through an exhibition.

Every section introduces something new.

Some sections move vertically.

Some sections become pinned.

Some sections scroll horizontally.

Some sections reveal content progressively.

Scrolling should become storytelling.

Never repetitive.

---

# Three.js Philosophy

Three.js exists to support storytelling.

Not decoration.

Objects should feel expensive.

Materials should feel premium.

Lighting should feel cinematic.

Movement should feel alive.

Ideas

Glass sculpture

Procedural geometry

Liquid chrome

Reflective crystal

Wireframe architecture

Particle systems

Volumetric lighting

Floating structures

Dynamic environments

Never use random spinning cubes.

Everything should have purpose.

---

# Typography Philosophy

Typography is the strongest visual element.

Use large headlines.

Confident spacing.

Editorial rhythm.

Readable paragraphs.

Generous line-height.

Avoid excessive font weights.

Headlines should animate gracefully.

Letters should feel alive.

Words should reveal naturally.
