# Frontend Standards

Use Server Components whenever possible.

Client Components only when required.

Never overuse "use client".

Prefer composition.

Avoid prop drilling.

Strong typing.

No any.

Reusable hooks.

Reusable utilities.

No duplicated JSX.

Use semantic HTML.

Always lazy load heavy components.

Always optimize images.

Always use next/image.

Always use dynamic imports for heavy Three.js scenes.

Never block rendering.

Avoid unnecessary state.
